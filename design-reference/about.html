02 — ABOUT

关于 About

软件工程在读，专注 AI 全栈与 Agent 开发。下面是一点背景与我做事的方式。

个人照片 / 头像
PORTRAIT

我在模型与产品之间，寻找优雅的接缝—— 让不确定的智能，收敛成确定、可用、可被信任的体验。

我是 fireflyx，一名软件工程方向的学生与开发者。日常游走于大模型编排、检索增强生成（RAG）、工具调用与评测，以及把它们包裹起来、让人愿意使用的前后端界面之间。

I care about restrained design, legible code, and open collaboration. 我相信好的工程有它自己的美学：克制、清晰、恰到好处。常在开源社区出没，乐于把踩过的坑写成工具与文章。

目前正在构建 AI Agent 相关的产品与基础设施，也对开发者体验（DX）格外上心。

工作方式 / How I work
01

先想清楚，再写代码

把模糊的需求收敛成清晰的问题边界，是工程里最值钱的一步。

02

让智能可被验证

为 Agent 与 Prompt 建立评测与护栏，让“看起来对”变成“可以证明对”。

03

克制即风格

少即是多。一个清晰的界面，胜过十个炫技的功能。

04

开放地协作

把工具与经验沉淀为开源，在社区里被验证、被改进。
